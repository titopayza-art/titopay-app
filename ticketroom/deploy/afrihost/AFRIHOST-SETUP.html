TicketRoom on Afrihost — setup guide

ticketroom.co.za · Powered by TitoPay

!First: remove what is public right now

In cPanel → File Manager → public_html, delete the folder ticketroom and the file ticketroom.zip. They expose the source code to anyone (that is the "Index of /" page). Then empty the File Manager trash.

1Upload and extract in your HOME folder

  1. File Manager → click Home (the folder that contains public_html, e.g. /home/youruser).
  2. Upload ticketroom.zip there, select it, click Extract, extract to the same Home folder.
  3. You now have ticketroom-app/ (the application — private) and new files inside public_html/ (a "Launching soon" page and a protective .htaccess).
  4. Delete ticketroom.zip from Home afterwards.

Visit http://ticketroom.co.za — you should see the TicketRoom "Launching soon" page instead of "Index of /". This works on every Afrihost plan.

2Switch on HTTPS

cPanel → SSL/TLS Status → tick ticketroom.co.za and www.ticketroom.co.za → Run AutoSSL. When it shows a valid certificate, edit public_html/.htaccess and remove the # from the three "RewriteEngine / RewriteCond / RewriteRule" lines at the bottom. Sign-in only works over HTTPS.

3Check your plan supports the app

The TicketRoom app needs two cPanel features. Look for them on the cPanel home page:

FeatureWhere in cPanelNeeded for
Setup Node.js App (Node 20 or newer)Software sectionRunning TicketRoom
PostgreSQL Databases (version 13 or newer)Databases sectionStoring events, tickets, payments

If either is missing, ask Afrihost support: "Please enable Setup Node.js App (Node 20+) and PostgreSQL 13+ databases on my cPanel account for ticketroom.co.za, or move me to a server that has them." If PostgreSQL is not offered, you can use an external managed PostgreSQL database in a South African region and paste its connection string as DATABASE_URL in step 5 (add ?sslmode=require). The holding page stays up meanwhile.

4Create the database and the mailbox

  1. cPanel → PostgreSQL Databases: create a database (e.g. ticketroom), create a user with a strong password, then Add User to Database with ALL PRIVILEGES. cPanel prefixes names with your username, e.g. youruser_ticketroom.
  2. cPanel → Email Accounts: make sure hello@ticketroom.co.za exists. Its SMTP settings are under Connect Devices (normally server mail.ticketroom.co.za, port 465, SSL).

5Configure the app

  1. File Manager → ticketroom-app → copy .env.example to .env (enable "Show Hidden Files" in File Manager Settings to see dot-files).
  2. Edit .env and fill in every CHANGE_ME: 
    DATABASE_URL=postgres://youruser_tr:DB_PASSWORD@localhost:5432/youruser_ticketroom
ADMIN_EMAIL=hello@ticketroom.co.za
ADMIN_PASSWORD=your temporary admin password
SMTP_PASS=the hello@ mailbox password
    If a password contains # @ : / ?, inside DATABASE_URL write it URL-encoded (# → %23, @ → %40). For ADMIN_PASSWORD and SMTP_PASS, wrap it in double quotes, e.g. ADMIN_PASSWORD="#Example123".
  3. Set the file's permissions to 600 (right-click → Change Permissions).

6Create the Node.js application

  1. cPanel → Setup Node.js App → Create Application:
    Node.js version22 (or 20 — not lower)
    Application modeProduction
    Application rootticketroom-app
    Application URLticketroom.co.za (leave the path empty)
    Application startup fileserver.js
  2. Click Create, then Run NPM Install and wait for it to finish.
  3. Click Restart.
  4. In File Manager delete public_html/index.html and the public_html/holding folder, so visitors reach the app. Keep public_html/.htaccess (cPanel has added lines to it — leave them).

Open https://ticketroom.co.za — the TicketRoom site loads. https://ticketroom.co.za/api/health shows "ok": true. The first start creates the database tables and your admin account.

If you get an error page: open ticketroom-app/stderr.log in File Manager. The first line says exactly what is wrong (for example a wrong database password, or PostgreSQL too old).

7Background jobs (cron)

Shared hosting can pause the app when nobody is visiting, which would pause ticket-reservation expiry and email delivery. cPanel → Cron Jobs → add one, every 5 minutes, with this command (copy the exact node path from the top of the Setup Node.js App page — the "source … activate" line shows your nodevenv folder):

cd /home/YOURUSER/ticketroom-app && /home/YOURUSER/nodevenv/ticketroom-app/22/bin/node scripts/run-jobs.js >/dev/null 2>&1

8Sign in and secure the admin account

  1. Go to https://ticketroom.co.za/admin and sign in with ADMIN_EMAIL and ADMIN_PASSWORD.
  2. Open My tickets → Settings & privacy and change the password.
  3. Delete the ADMIN_PASSWORD line from .env and Restart the app.

9Back up

  • ticketroom-app/var/secrets.json — generated on first start. Download a copy and keep it safe. Without it every issued ticket QR code and registered tag stops working.
  • ticketroom-app/.env and the PostgreSQL database (cPanel → Backup).

What works on day one

Public site, accounts, organiser sign-up and portal, free events with QR tickets, gate scanning with live counts, admin, email through your mailbox. Paid ticket sales stay closed (PAYMENT_PROVIDER=none) until a card gateway (Yoco or PayFast) is connected — then set its keys in .env and restart. SMS and the TitoPay wallet are switched on the same way.

Updating to a new version

Upload the new ticketroom.zip to Home, extract (overwrite), do not overwrite .env or var/, click Run NPM Install then Restart. Database changes are applied automatically on start.
