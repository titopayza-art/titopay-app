Your systems talk to one SeaGeek API. Behind it, we route each request to licensed upstream networks and can switch providers without changing the API you call.

# Send an OTP by SMS
curl https://api.seageek.co.za/v1/sms/messages \
  -H "Authorization: Bearer $SEAGEEK_KEY" \
  -H "Idempotency-Key: order-10294-otp" \
  -d '{
    "to": "+27821234567",
    "from": "SeaGeek",
    "body": "Your verification code is 482913"
  }'
import { SeaGeek } from "@seageek/node";

const sg = new SeaGeek(process.env.SEAGEEK_KEY);

const msg = await sg.sms.send({
  to: "+27821234567",
  from: "SeaGeek",
  body: "Your verification code is 482913",
}, { idempotencyKey: "order-10294-otp" });

console.log(msg.status); // "queued"

sg = SeaGeek(os.environ["SEAGEEK_KEY"])

    sender="SeaGeek",
    body="Your verification code is 482913",
    idempotency_key="order-10294-otp",
)
print(msg.status)  # "queued"

Trust & compliance

Pressure-tested for the deep end.

Messaging and identity services handle personal information. We design for security and privacy from the start, and we don't onboard customers to a product until it passes its operational-readiness checks.

Security controls

  • Encryption in transit & at rest
  • Multi-tenant data isolation
  • Role-based access & audit logs
  • Signed webhooks & idempotency
  • Rate limits & abuse protection
  • Sandbox / production separation
  • Backups with restore testing
  • Penetration testing
  • Privileged access reviews
  • Incident response procedures

Regulatory approach

POPIALawful processing, data minimisation, retention policies, support for data-subject rights and controls on cross-border transfers.
ICASA / ECALicensing assessed against the telecommunications activities we actually carry out.
ConsentOpt-out and suppression enforced by default. Customers agree by contract to use messaging lawfully.
FIC ActVerification products launch only with licensed upstream data and a legal review.
Responsible AIModel evaluations, sensitive-data handling and human approval for consequential actions.
