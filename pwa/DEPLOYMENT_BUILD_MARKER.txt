This build — the ticketing sheet becomes a hub, and simplicity gets rules:

  BUSINESS TICKETING IS NO LONGER ONE LONG SHEET.
  It was one screen doing events, sales, vendors, cashless and blank-tag
  issuing at once. Linking a vendor meant scrolling past everything else,
  and any refresh threw you back to the top. It is now a hub with four
  short doors:
    My Events        create, submit for approval, track each event
    Sales            tickets sold and money taken, per event and per tier
    Vendors & Door   who may take Event Tag payments; door scanning
    Event Tags       cashless on/off, issue blank tags, assign a tag
  The events load ONCE at the hub and every door renders from that same
  data — no door fetches for itself. A save re-renders only its own door,
  at the scroll position you were at, so nothing jumps. Each door carries
  a back arrow to the hub.

  Sales is new here: it gathers the numbers the event rows already carried
  into one place and totals them — tickets sold, money taken, and a line
  per ticket tier.

  NO EMPTY TILES. Event Scanners now stays out of the way until one of
  your events is approved. It fails open on purpose: an account TitoPay
  has not looked at yet still sees the tile, and it costs no extra request
  — the answer comes from data already fetched. (Products & Stock needed
  no change: it already lives inside Sales rather than as its own tile.)

  FIXED: the small counters at the top of ticketing rendered as bare text
  ("1Draft") — the .metric-card class had never had a style rule behind
  it. They are cards now.

  SIMPLICITY.md is new at the repo root: one door per feature, three taps
  from home, a sheet does one job, no empty tiles, one name per concept,
  and the money rules that outrank all of them. api/test/app-navigation-
  simplicity.test.js enforces the first four — it fails if a feature grows
  a second door, if a single-door feature is missing from app search, if
  the ticketing hub grows past five doors or a door starts fetching for
  itself, or if a self-hiding tile stops failing open. Verified by
  injecting each regression and watching the test fail.
