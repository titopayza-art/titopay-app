This build — gifted tickets can be added to the recipient's account:

  - My Tickets gains "Been gifted a ticket?": enter the ticket code from
    the gifted ticket's email, PDF or stub (a pasted ticket-QR payload
    works too). The ticket moves into the recipient's account under their
    name — it shows in My Tickets with its scannable QR, the gate admits
    it as before, and the event wristband (Event Tag) becomes theirs to
    link, exactly like a ticket they bought.
  - Safety, because a code alone moves ownership:
      * the previous holder is notified IN THE APP and BY EMAIL the moment
        the ticket moves — a gift expects the message, a stolen code turns
        it into the alarm that gets support to reverse it;
      * code guessing is throttled hard (8 misses an hour per account,
        durable across restarts via the audit log);
      * used (scanned) tickets, invalid tickets and tickets at suspended
        or cancelled events refuse the claim;
      * a ticket with a live wristband already linked refuses until the
        giver unlinks it — a tag never silently ends up on someone else's
        entry;
      * every attempt, hit or miss, is on the event audit trail.
  - New endpoint POST /v1/ticketing/tickets/claim. No schema changes.
