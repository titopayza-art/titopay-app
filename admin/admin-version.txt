v34 - Support Desk rebuilt as a workspace
  - Taking over a chat now opens that conversation as the page, with one "Back
    to queue" control. Previously the conversation was appended below three
    stacked tables, so an agent who took over was left looking at the queue with
    the conversation off-screen.
  - The queue shows one list at a time behind tabs (Live conversations,
    Tickets, Profile approvals) instead of three tables on one page.
  - Metrics reduced from eight tiles to the four a support desk acts on.
  - Conversation queue trimmed to five columns so nothing is hidden under the
    pinned action column.
  - Fixed: a customer's incoming message did not appear while the agent had the
    reply box focused, which is exactly when an agent is waiting for it. The
    draft, the caret position and focus now survive the live refresh, so the
    guard that suppressed it is gone.

v33 - Rate-limit and lockout messages reach the operator verbatim.
v32 - Support workspace preserved across refreshes; CSP allows the chat socket.
v31 - Sign-in page rebuilt for a regulated system.
v30 - Operations console front-end rebuild on a single-layer stylesheet.

No API endpoint, authentication, routing or permission behaviour is changed by
the admin package. Assets are versioned ?v=admin-console-v34; hard refresh
(Ctrl+F5 / Cmd+Shift+R) if an old layout persists.
